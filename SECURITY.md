# Security reporting

This application runs locally and has no network features or runtime third-party
dependencies. Report ordinary rendering, simulation, and installation bugs through
the repository issue tracker once it is public.

For a security-sensitive report, use the repository's private vulnerability
reporting feature if enabled. Do not include secrets in a public issue. Maintainers
should enable private vulnerability reporting when making the repository public.

Only the latest released version will receive fixes. No releases have been
published yet. Release workflows use manually selected environments and PyPI
Trusted Publishing; maintainers should restrict the production environment to
version tags and review changes to workflows before publishing.
